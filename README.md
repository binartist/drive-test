# drivetest.app

Public NZ driving guide — starting with a **travel** track for newcomers (North Island focus), with room to grow a **licence-test** track later.

## Tracks (planned)

- **Travel** — keep left, roundabouts, parking, petrol, visitor safety (live in this site now)
- **Licence test** — road code depth and practice aligned with official Drive / Waka Kotahi resources (coming)

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8765
```

## GitHub Pages

This repo is meant to publish from the `main` branch root (`/`).
